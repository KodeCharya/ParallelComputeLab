# Results

This directory holds measurement output.  Nothing here is checked in except the
reference material described below, because a committed timing from someone
else's machine says nothing about yours.

```
results/
├── raw/          one .json + .meta.json + .log + .system.json per run
├── analysis/     generated by scripts/analyze_results.py
└── reference/    small, curated, human-checkable reference material
```

## File naming

| File | Produced by | Contents |
|---|---|---|
| `<label>.json` | `pcl_benchmarks --benchmark_out` | raw Google Benchmark measurements, every repetition preserved |
| `<label>.meta.json` | the harness | machine, compiler, flags, dependency provenance, seed, byte-counting convention |
| `<label>.log` | the shell | full console output of the run |
| `<label>.system.json` | `scripts/collect_system_info.py` | independent record of the host, collected before the run |

A result set is only usable if the `.meta.json` exists.  `scripts/validate_results.py`
enforces that, because an unattributed number cannot be reproduced.

## Reproducing a run

```bash
python3 scripts/run_benchmarks.py --build build/gcc --preset full --label gcc-release
```

That command writes all four files above and then validates them.  The exact
command line used for any run is recorded verbatim in the `.meta.json` under
`command_line`.
